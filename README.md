# מבעד לעדשה - אביאל מלכא | אתר צלם אירועים

אתר תדמית ולידים עבור אביאל מלכא, צלם אירועים (בריתות, עלייה לתורה, חינה, חלאקה, צילומי זוגיות ו-Save the date).

אתר סטטי (Eleventy) עם מערכת ניהול תוכן (Sveltia CMS) שמאפשרת ללקוח לערוך טקסטים ותמונות בעצמו, בלי קוד.

## מבנה

| נתיב | תפקיד |
|---|---|
| `src/index.njk` | התבנית - כל ה-HTML וה-CSS של האתר |
| `src/_data/*.json` | **התוכן** - כל טקסט, תמונה ומחיר. זה מה שה-CMS עורך |
| `src/assets/img/` | תמונות (הלוגו ותיק העבודות) |
| `admin/` | ממשק ניהול התוכן - זמין בכתובת `/admin` |
| `api/` | שרת ההתחברות ל-CMS (OAuth מול GitHub), פונקציות serverless ב-Vercel |
| `_site/` | תוצר הבנייה (לא נשמר ב-git) |
| `vercel.json` | הגדרות פריסה ב-Vercel |
| `serve.mjs` | שרת מקומי לתוצר הבנייה |
| `screenshot.mjs` | כלי צילום מסך לבדיקה (puppeteer-core + Chrome מקומי) |

## הרצה מקומית

```bash
npm install
npm run dev      # http://localhost:3100, בנייה מחדש בכל שינוי
npm run build    # בנייה חד פעמית ל-_site
```

## עריכת תוכן

- **הלקוח**: דרך `/admin` באתר החי. ראה [מדריך-לאביאל.md](מדריך-לאביאל.md).
- **מפתח**: עריכה ישירה של `src/_data/*.json`.

הקמת ה-CMS (חד פעמי - Worker, OAuth, הרשאות): [CMS-SETUP.md](CMS-SETUP.md).

## תכונות

- SEO מלא: meta tags, Open Graph, Twitter Card, JSON-LD (Photograph + Service) - נבנים מהתוכן, כך שעדכון בממשק מתגלגל גם לגוגל.
- CTA מבוססי וואטסאפ + בר פעולה דביק במובייל.
- טופס יצירת קשר שנפתח ישירות בוואטסאפ עם פרטי הפנייה (ללא צורך בשרת).
- רספונסיבי, נגיש (focus states, prefers-reduced-motion), תמיכה מלאה ב-RTL.
- אופטימיזציית תמונות אוטומטית בבנייה (WebP + srcset בארבעה רוחבים), כך שגם תמונה כבדה שמועלית מה-CMS לא מאטה את האתר.

## לפני עלייה לאוויר - לעדכן

1. **המלצות** - להחליף בביקורות אמיתיות (ממשק הניהול ← המלצות לקוחות).
2. **דומיין** - להחליף `aviel-malka.co.il` בכתובת האמיתית (ממשק הניהול ← פרטים כלליים ← כתובת האתר).
3. **רשתות חברתיות** - להוסיף קישורים (ממשק הניהול ← גוגל ורשתות חברתיות).
